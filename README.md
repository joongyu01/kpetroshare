# K-Petro Share

## 자동 갱신 (2026-10-23)

- GitHub `main`에 푸시하면 기존 Vercel 프로젝트로 배포합니다.
- Actions의 **Refresh shared resources**는 매일 한국시간 08:17경 실행합니다. GitHub 상황에 따라 지연될 수 있으며 **Run workflow**로 즉시 실행할 수 있습니다.
- 공유누리 전체 페이지와 내부 상세를 새로 수집합니다. 검색 건수 불일치, 중복 페이지, 상세 파싱 실패, 20% 초과 감소 시 기존 파일을 유지하고 작업을 실패 처리합니다.
- ZEUS 등 외부 연계는 공유누리 목록만 확인합니다. 알리오플러스 단독 보완 항목은 기존 확인일을 유지합니다.
- 화면의 작은 통계창에 최근 변경이 있었던 갱신의 본부별 추가/정보 변경/제외 건수를 표시합니다. 정보 변경은 저장된 이름·분류·주소·요금·조건 등의 차이이며, 원본 기관의 수정일을 뜻하지 않습니다.
- 방문자는 Vercel Web Analytics로 수집하고 Actions가 한국시간 일별 집계를 `public/data/traffic.json`에 저장합니다. 개인 식별자나 API 토큰을 공개 파일에 넣지 않습니다.
- GitHub Actions secret `VERCEL_ANALYTICS_TOKEN`이 필요합니다. 방문 집계 실패는 자원 갱신을 막지 않으며 마지막 집계 시각이 화면에 남습니다. 과거 미수집 기록은 0으로 만들지 않습니다.
- 테스트: `node --test scripts/*.test.mjs`. 수동 수집: `node scripts/sync-resources.mjs`.

아래 내용은 최초 구축 당시의 자료와 검증 기록입니다.

한국석유관리원 공유 물품 안내 지도. Vite + JavaScript + D3 Geo로 구성한 정적 웹사이트입니다.

## 자료

- `public/data/items.json`: 2026-09-30 공유누리 물품(대여) 목록 87건. 상세 페이지 87개를 확인해 주소, 전화, 이용조건을 추가했습니다. 물품 카드의 원문 링크로 예약합니다.
- `src/branches.js`: 본부 구분과 지역 선택용 표시 위치. 지도 점은 지역 안내용이며 정확한 위치를 찾을 때는 주소 기반 카카오맵 링크를 사용합니다.
- `public/data/korea.geojson`: geoBoundaries KOR ADM1, boundary ID KOR-ADM1-68945753, represented year 2021, Natural Earth source, Public Domain. 현대 행정구역 경계 및 본부의 관할구역을 정밀하게 나타내는 지도가 아닙니다.
- 수도권남부/광주전남본부는 이번 물품 분류에서 확인되지 않았으므로 0건 확정 대신 '미확인'으로 표시합니다.
- 요금과 물품 목록은 실시간 재고가 아닙니다. 최신 예약 조건은 공유누리에서 확인합니다.

## 전체 개방자원 확장 (2026-09-30)

- 서비스 데이터: `public/data/resources.json` (153개, 10개 기관, 6개 유형).
- 공유누리 통합검색 154건과 알리오플러스 시설 5건·물품장비 39건을 대조했습니다. 동일 자원의 알리오플러스 링크는 합쳤습니다.
- 본사 주차장 중복 1건과 2026-03-31 종료 교육 1건 제외, 알리오플러스 단독 등록 충북본부 전지톱 1건 추가.
- ZEUS 연계 장비 39건은 공유누리 공개 목록 확인 기준입니다. 등록번호가 다른 장비를 이름만으로 합치지 않았습니다. 상세 요금/이용조건은 ZEUS 원문에서 확인합니다.
- 유형: 물품 88, 연구·실험장비 58, 회의실·공간 3, 주차장 2, 체육시설 1, 교육·강좌 1.
- 본사 테니스장 요금과 주차장 운영시간은 출처 간 또는 원문 내부 불일치 안내를 표시합니다. 무료 필터에서 테니스장을 제외합니다.
- 실시간 예약 현황 및 만족도 점수는 표시하지 않습니다. 실제 설문을 만든 뒤 `public/data/site-config.json`의 `satisfactionUrl`에 HTTPS URL을 설정하면 설문 링크가 나타납니다.
- 기관 QR은 기관별 목록, 자원 QR은 공식 상세 페이지를 연결합니다.
- 현재 검색은 자원명·지역·종류를 대상으로 하는 키워드 검색이며 AI 모델을 호출하지 않습니다.
- 수집/대조 스크립트와 캐시는 `work/`에 있습니다. 공개 배포에는 포함하지 않습니다.

- 자원 사진은 원문 공개 이미지 URL을 사용하며, 로딩 실패 시 유형 아이콘으로 대체합니다. 지역명은 branches.js의 기존 region 값을 그대로 표시합니다.

최근 동기화 완료 시각(한국시간, 초 단위)과 해당 실행의 추가·변경·삭제 건수를 별도로 표시합니다. 변화가 없으면 0건이며, 마지막으로 변경이 발생한 실행의 그래프는 확인 시각을 붙여 보존합니다. 삭제는 공유누리의 정상 수집 목록에서 빠진 자원에 적용되며, 알리오플러스 단독 보완 항목은 자동 삭제 대상이 아닙니다.
